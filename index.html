Onze Samenwerking

Deze website is een gezamenlijk project, waar we leren om samen in een repository te werken.

Ook leren we hoe we via pull requests elkaars werk kunnen bekijken en verbeteren.

Dit gebeurd allemaal in de les van DJ Sjollema op donderdag.

De samenwerking ging mediocre maar we zijn er wel uit gekomen samen.

Met genoeg tijd, hulp van elkaar en de leraar zijn we er toch uit gekomen.

We hopen dat we in de toekomst nog meer van dit soort projecten gaan doen.

Doordat we leren samen te werken kunnen we dit gebruiken voor de toekomst.
